# LJ Gaming — página de vendas

Site estático (sem servidor) publicado pelo GitHub Pages. Fica fora do Render para o tráfego dos anúncios não gastar banda do servidor de licenças.

- `index.html` — página de vendas (checkout no GGCheckout).
- `assets/` — estilos, marca, fotos dos consoles e capas (reduzidas para carregar rápido).
- A área de membros continua no servidor de licenças (link "Área de membros" no topo).
